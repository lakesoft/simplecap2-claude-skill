## English

### When to use this skill

Reach for this skill whenever the user wants Claude to interact with their
SimpleCap2 capture archive or trigger a new capture from chat:

- **Interactive capture**: "Take a screenshot of this region and explain
  what's wrong", "Capture that window and summarise it" — start a region or
  window capture inside SimpleCap2, wait for the user to drag/select, and
  read the resulting image.
- **Archive search**: "Make a Markdown report from my Red-tagged screenshots",
  "List all my Blue-tagged captures from this week" — query the gallery by
  Finder color tag, return a JSON list, then read the relevant images
  individually.

### Prerequisites

- SimpleCap2 1.x installed (Mac App Store).
- The user has selected a save folder inside the app at least once.

Run `${CLAUDE_PLUGIN_ROOT}/bin/simplecap-version` first to confirm
compatibility. The output ends with `schemaVersion=1`; this skill is built
for that schema.

### Available commands

All commands live under `${CLAUDE_PLUGIN_ROOT}/bin/`. Each script verifies
the SimpleCap2 bundle's Apple Developer Team ID against `EDF37AMEEW` to
reject tampered binaries or same-bundle-id imposters.

#### `simplecap-version`

Prints the app's version and CLI schema version. Use it to gate features.

```bash
${CLAUDE_PLUGIN_ROOT}/bin/simplecap-version
# → SimpleCap2 1.0.0 (42) schemaVersion=1
```

#### `simplecap-folder`

Prints the absolute path of the configured capture save folder.

```bash
${CLAUDE_PLUGIN_ROOT}/bin/simplecap-folder
# → /Users/foo/Pictures/SimpleCap
```

#### `simplecap-list [COLOR|untagged] [--limit N] [--offset N]`

Lists captures as JSON (`schemaVersion: 1`).

`COLOR` accepts:

- English: `red`, `orange`, `yellow`, `green`, `blue`, `purple`, `gray`.
- Finder label number: `1`–`7`.
- Localized Finder name: Japanese, French, German, Spanish, Italian,
  Korean, Chinese (Hans/Hant), Portuguese, Russian.
  e.g. `赤`, `Rouge`, `Rot`, `Rojo`, `Rosso`, `빨강`, `红色`, `紅色`,
  `Vermelho`, `Красный`.

`untagged` filters to captures with no color tag. Omit the argument for all
captures.

Default `--limit 50`. Pass `--limit 0` for unlimited (be careful with token
usage). Use `--offset` to page through.

JSON shape:

```json
{
  "schemaVersion": 1,
  "appVersion": "1.0.0 (42)",
  "folder": "/Users/foo/Pictures/SimpleCap",
  "totalCount": 234,
  "offset": 0,
  "limit": 50,
  "captures": [
    {
      "path": "/abs/path/file.png",
      "name": "file.png",
      "sizeBytes": 12345,
      "capturedAt": "2026-04-30T12:34:56.000Z",
      "modifiedAt": "2026-04-30T12:34:56.000Z",
      "tags": ["Red"],
      "processed": false
    }
  ]
}
```

Captures are sorted newest first by `capturedAt`. The `tags` array uses the
canonical English Finder names regardless of which locale name the user
filtered by, so downstream code can match on `"Red"`/`"Blue"`/etc.

`processed: true` means the file was generated by a SimpleCap2 preset
pipeline (resized, recompressed, etc.).

#### `simplecap-capture region|window [TIMEOUT_SECONDS]`

Triggers an interactive capture and prints the resulting file path on
stdout once the user finishes. Default timeout: 60 s, override with
`SIMPLECAP_TIMEOUT` env var or the second positional arg.

```bash
${CLAUDE_PLUGIN_ROOT}/bin/simplecap-capture region 90
# user drags...
# → /Users/foo/Pictures/SimpleCap/20260430_173045.png
```

If the user cancels (Esc) or no new file appears within the timeout, the
script exits with code 2 and writes a diagnostic to stderr.

While a capture is in flight, the SimpleCap2 gallery shows a red "external
trigger" indicator in its title bar and overlay action bar — so the user
always knows Claude initiated this.

### Recommended flow

1. **Compatibility check (once per session)**:
   `simplecap-version` → confirm `schemaVersion=1`.
2. **Search**: `simplecap-list red` → parse JSON → `Read` the relevant
   `path`s individually. Don't pre-load all images; pull each only when
   needed.
3. **Interactive capture**: `simplecap-capture region` → read the returned
   path with `Read`. The image is now under the user's chosen save folder
   and persists.

### Important caveats

- **PII / sensitive content**: Screenshots can contain credentials, email,
  internal info. Even after a tag-filtered query, the user may have tagged
  sensitive captures unintentionally. Confirm before quoting/summarising
  publicly. Drop image references from the conversation when no longer
  needed.
- **Don't read xattrs directly**: Always go through `simplecap-list`. The
  app handles the Finder tag format (binary plist with `\nN` label number
  suffix), the SimpleCap-specific `processed` and `capturedAt` xattrs, and
  the multi-language label resolution. Bypassing the CLI risks subtle
  format drift.
- **Concurrency**: Two parallel `simplecap-capture` calls in the same
  folder will see each other's results via mtime polling. Run captures
  sequentially per session.
- **Cancellation isn't reported precisely**: mtime polling cannot tell the
  difference between "user pressed Esc" and "user took 60 s to align the
  selection". On exit code 2, ask the user whether they cancelled or just
  needed more time.

## 日本語

### このスキルを使う場面

- **対話キャプチャ**：「この範囲をキャプチャして説明して」「あのウィンドウを撮って要約して」など、ユーザがその場でスクショを撮らせて Claude に処理させたい
- **過去資産検索**：「Red タグの画像で資料作って」「先週撮った Blue タグのスクショを列挙して」など、SimpleCap2 で蓄積したキャプチャを Finder カラータグで検索したい

### 前提条件

- SimpleCap2 1.x がインストール済み（Mac App Store）
- アプリで保存先フォルダを 1 度設定済み

セッションの最初に `${CLAUDE_PLUGIN_ROOT}/bin/simplecap-version` を実行し、末尾に `schemaVersion=1` が含まれることを確認してください。本スキルは schemaVersion 1 用です。

### 提供コマンド

すべて `${CLAUDE_PLUGIN_ROOT}/bin/` 配下にあります。各スクリプトは SimpleCap2 の Apple Developer Team ID（`EDF37AMEEW`）を `codesign` で検証し、改ざんバイナリや同 bundle ID 名乗りの偽アプリを排除します。

#### `simplecap-version`

バージョンと CLI スキーマバージョンを表示。互換性確認用。

```bash
${CLAUDE_PLUGIN_ROOT}/bin/simplecap-version
# → SimpleCap2 1.0.0 (42) schemaVersion=1
```

#### `simplecap-folder`

設定済みの保存先フォルダの絶対パスを表示。

```bash
${CLAUDE_PLUGIN_ROOT}/bin/simplecap-folder
# → /Users/foo/Pictures/SimpleCap
```

#### `simplecap-list [色名|untagged] [--limit N] [--offset N]`

ギャラリーを JSON で列挙。

色名は次のいずれか：

- 英語：`red` / `orange` / `yellow` / `green` / `blue` / `purple` / `gray`
- Finder ラベル番号：`1`〜`7`
- 日本語 Finder 名：`赤` / `オレンジ` / `黄` / `イエロー` / `緑` / `グリーン` / `青` / `ブルー` / `紫` / `パープル` / `グレイ`
- 仏語・独語・西語・伊語・韓語・中文（簡体/繁体）・葡語・露語の Finder 名

`untagged` で「タグ無し」のみ。引数省略で全件。

デフォルト `--limit 50`。`--limit 0` で無制限（ただし AI コンテキストを大量消費するので注意）。`--offset` でページング可。

出力 JSON 形式は英語版を参照。`tags` は常に英語名（`"Red"` 等）で返るので、ユーザがどのロケール名で絞り込んでもダウンストリーム処理は統一して書けます。

`processed: true` は SimpleCap2 のプリセット加工（リサイズ・再圧縮など）を経たファイルであることを示します。

#### `simplecap-capture region|window [TIMEOUT_SECONDS]`

対話キャプチャを起動し、ユーザの操作完了後に保存パスを stdout に返します。デフォルトタイムアウト 60 秒、`SIMPLECAP_TIMEOUT` 環境変数または第2引数で上書き可能。

```bash
${CLAUDE_PLUGIN_ROOT}/bin/simplecap-capture region 90
# ユーザがドラッグ……
# → /Users/foo/Pictures/SimpleCap/20260430_173045.png
```

ユーザが Esc でキャンセルした、あるいはタイムアウト内に新規ファイルが現れなかった場合は exit 2、診断メッセージは stderr。

キャプチャ実行中は SimpleCap2 ギャラリーのタイトルバーとオーバーレイのアクションバーに赤い「外部要求中」インジケーターが表示され、Claude が起動したことがユーザにわかります。

### 推奨フロー

1. **互換性確認（セッション初回のみ）**：`simplecap-version` で `schemaVersion=1` を確認
2. **検索系**：`simplecap-list red` で JSON 取得 → 必要な `path` を `Read` で個別に読む。全件を一度に読み込まない
3. **対話キャプチャ系**：`simplecap-capture region` → 返ったパスを `Read`。ファイルはユーザ指定の保存フォルダに残ります

### 重要な注意

- **PII／機密情報**：スクリーンショットは認証情報・メール・社内情報が映り込みやすい媒体です。タグでフィルタしても、ユーザが意図せず機密を含む画像にタグを付けた可能性があります。公開／要約前に確認を促し、不要な画像参照は会話履歴から外してください。
- **xattr を直接読まない**：必ず `simplecap-list` 経由で。Finder のタグ形式（`\nN` 接尾辞付き binary plist）、SimpleCap2 独自の `processed` / `capturedAt` xattr、多言語ラベル名の解決はすべてアプリ側で集約しています。CLI を経由しないと将来のフォーマット差分で壊れます。
- **並行実行**：同じフォルダで `simplecap-capture` を 2 つ並行で動かすと mtime 検知が混線します。セッション内では 1 リクエストずつ。
- **キャンセル検知の限界**：mtime ポーリングでは「Esc を押した」のと「ユーザが選択に時間をかけている」が区別できません。exit 2 のときは、本当にキャンセルしたのかタイムアウトを伸ばしたいのか、ユーザに聞いてください。
